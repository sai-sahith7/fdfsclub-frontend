# Security policy

## Reporting a vulnerability

Please don't report security issues in public issues, discussions or pull requests.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/sai-sahith7/fdfsclub-frontend/security/advisories/new). Include:

- what the issue is and what an attacker could do with it
- steps to reproduce, or a proof of concept
- the affected page, URL or file

You'll get a reply within 7 days. Once the issue is confirmed, we'll work on a fix and let you know when it's live. With your permission, we'll credit you in the advisory.

Issues in the API, sign-in, alerts, emails or the Telegram bot belong to [fdfsclub-backend](https://github.com/sai-sahith7/fdfsclub-backend/security/advisories/new).

## Supported versions

Only the live site at [fdfsclub.in](https://fdfsclub.in), deployed from `master`, gets security fixes.

## Scope

Please don't:

- access, change or delete other people's data
- run automated scans or load tests against fdfsclub.in
- use social engineering or phishing

Test only with accounts you own.
